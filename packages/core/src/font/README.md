# Fonts

Text is drawn from font files: `FontManager.ts` loads and parses them with opentype.js, and the glyph outlines go through the same pipeline as any other path. Inter comes with the app (`apps/web/src/services/bundledFonts.ts`); the other families come from Google Fonts.

## The Google Fonts catalog — `googleFonts.json`

The families the editor offers from Google Fonts, most popular first:

```json
[
  {
    "family": "Roboto",
    "category": "sans-serif",
    "weights": [100, 400, 700],
    "files": { "400": "https://fonts.gstatic.com/…ttf" }
  }
]
```

`FontManager.ts` builds `GOOGLE_FONTS_CATALOG` from it.

### Where it comes from

It is generated by `packages/core/scripts/google-fonts.mjs` from two public Google Fonts endpoints, neither of which needs an API key:

- **https://fonts.google.com/metadata/fonts** lists every family with its category, popularity rank and styles. The generator takes the 300 most popular families (ties by name) that are open source, not colour fonts (opentype.js draws outlines only) and have upright styles. It leaves out Inter, which comes with the app, and keeps every family the editor offered before the catalog was generated (documents use them), whatever their rank.
- **https://fonts.googleapis.com/css2?family=Name:wght@400;700…** gives each weight's file. Asked with no User-Agent, the CSS API answers with TrueType URLs, one static instance per weight; the generator keeps only those (no variable files, no WOFF2, no italics). The weights are the ones Google actually serves, which can be fewer than the metadata lists.

The output is sorted by popularity and formatted with the repo's Prettier settings, so a refresh only changes what Google changed: new font versions (the `/v51/` in a URL), new weights and shifts in popularity.

### Refreshing it

```bash
pnpm --filter @quar/core fonts:catalog            # about 300 requests, four at a time
pnpm --filter @quar/core fonts:catalog --verify   # also checks every file is a static TrueType font
```

`--count N` changes how many families it takes, and `--concurrency N` how many requests run at once. Failed requests are retried with exponential backoff, following Retry-After when Google sends one. A family Google won't serve as static TTFs is skipped and the next one taken. If one of the kept families is gone, the generator stops without writing anything. Old URLs keep working after Google publishes a new version, so a refresh is never urgent.

### Licences

The families are published under the SIL Open Font License 1.1, except a few that use the Apache License 2.0 or the Ubuntu Font Licence 1.0. Each family's licence is on its Google Fonts page. This repository doesn't bundle or redistribute any of them: the catalog only lists URLs, and the editor downloads a font from Google's servers at run time, after the user has allowed Google Fonts (`ensureGoogleFontsConsent` in `apps/web/src/components/common/ConsentBanner.tsx`). None of these licences limit what can be done with documents or exports made using the fonts.
